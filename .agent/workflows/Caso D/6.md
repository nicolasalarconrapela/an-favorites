## Pull Request

Está permitido leer `"$VAR_S1_FILE"` únicamente para obtener variables necesarias de este paso.

No está permitido usar ninguna otra fuente.

Objetivo:

Generar `PR_TITLE.txt` y `PR.txt` dentro de `"$OUTPUT_DIR"` para sincronizar `main` hacia `develop`.

- `PR_TITLE.txt` debe contener únicamente el título del Pull Request
- `PR.txt` debe contener únicamente el cuerpo del Pull Request

### 5.3 Generar borrador de PR_TITLE.txt y PR.txt

#### PR_TITLE.txt

**El título debe ser exactamente:**

```text
Sync main back into develop after release <RELEASE_VERSION>
```

#### PR.txt

```markdown
## Summary

Standard post-release synchronization to propagate all official changes published in `main` (version <RELEASE_VERSION>) back into the `develop` branch. This ensures consistency for the next development cycle.
```
